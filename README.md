# MINDPRINT — IQ CHALLENGE

ブラウザで楽しめる、全10問のインタラクティブIQチャレンジです。

## Features

- 数列・論理・図形・言語・空間認識の全10問
- 8分タイマーと進捗表示
- 推定IQレンジと思考タイプの結果表示
- 全問題の回答解説
- 自己ベストのローカル保存
- PC・スマートフォン対応

> このテストは娯楽・自己理解を目的とした簡易テストです。正式なIQ検査ではありません。

## Development

```bash
npm install
npm run dev
```

## Production build
